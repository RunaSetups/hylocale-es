# HyLocale ES

**Capa de localización en español para plugins de servidores de Hytale.**
*Spanish localization layer for Hytale server plugins.*

> 🚧 **En desarrollo.** Todavía no hay una versión publicada.

HyLocale ES traduce al español los mensajes, menús y textos de plugins populares de Hytale, para que los dueños de servidores hispanos no tengan que traducir cada config a mano después de cada actualización.

## Qué hace

- **Paquetes de idioma** en español para plugins populares.
- **Override de mensajes por clave:** reemplaza solo los textos traducidos, sin tocar el resto de la configuración del plugin.
- **Detector de textos sin traducir:** un comando que lista los mensajes que siguen en inglés, para saber qué falta.
